# Company Branding

Two jobs. First **capture** the company's style rules once, into
`/workspace/.gtm-brain/style-guide.md`. Then **apply** them to everything
written afterwards. If the guide exists, you're in apply mode; if not, offer
setup.

## Setup — build the guide in one pass

Don't make the user write it from scratch, and don't try to yourself from
nothing:

1. **Gather.** A your-move Ask: drop into `/workspace/brand/` any existing
   style or brand guidelines, 10–20 pieces of published on-brand content,
   and messaging docs. If they follow AP or Chicago, they say so. Whatever
   arrives is enough — three blog posts alone produce a usable inferred
   guide.
2. **Infer.** Read it all and draft the full guide as a **doc artifact**,
   with every rule inferred from content (rather than read in a guide)
   marked as a **suggestion** for the user to accept or correct in place.
3. **The two deliberate decisions.** One decision Ask, two questions: em
   dashes — allowed or banned? Oxford comma — yes or no? Both are house
   choices, both visible on every page, both endless re-litigation if left
   unstated.
4. **Confirm terminology.** Voice you'll get roughly right; **product
   terminology you cannot infer reliably, and it matters most** — a wrong
   product name reads as someone who doesn't work here. Present the
   terminology table for explicit confirmation before marking the guide
   live.

## The guide's sections

- **Voice** — four qualities, each with what it means AND a matched pair
  (on-brand line / off-brand line; the pairs do more work than the
  adjectives). Example shape: _Credible_ = let data do the work; on-brand
  "39.7% of sensitive data shared with AI tools is regulated"; off-brand "a
  staggering amount of data is at risk." Same fact; only one is checkable.
- **Tone by content type** — voice is constant, tone moves: blog, datasheet,
  glossary, sales enablement, email, social.
- **What we are not** — explicit failure modes (no fear-mongering, no hype
  without substantiation, no mocking competitors). A prohibition is easier
  to follow than an ideal.
- **Grammar hard rules** — the cheap-to-check ones: Oxford comma, dashes,
  contractions, active voice, casing, numbers, acronyms, exclamation points.
  "No house rule" is a legitimate recorded answer.
- **Words to avoid** — the highest-value table because it's enforceable:
  word + what to use instead. A ban without a replacement gets ignored. The
  test: could a competitor paste the sentence into their own site unchanged?
- **Product terminology** — per term: capitalization, expansion on first
  use, allowed short forms, "do not conflate with" the generic category
  term. Key differentiators with the precise language. Competitor names
  exact, compared on capabilities, never character. Compliance is an
  outcome, not a feature — "ensures compliance" needs legal review.
- **Formatting** — headline case and length, paragraph ceiling, bullet
  depth, link text, CTA count per asset type.

## Apply mode — silent, on every voice deliverable

Before any draft leaves — blog, email, social, deck copy, web copy — run the
pre-delivery checklist derived from the guide's actual rules: hard rules
applied, banned words out, casing right, numbers formatted, acronyms
defined, product names exact, statistics sourced. Fix violations silently
where mechanical; where a fix would change meaning, leave it as a doc
suggestion instead. Don't narrate the checklist in chat.

Keep the guide current: when the user corrects your copy in a way that
implies a rule, propose adding it to the guide (one line in chat) — rules
change in the guide, never as per-document exceptions.

## What this will not do

- It will not invent terminology. Blank slots stay blank; a guessed product
  name is worse than an empty one.
- It will not settle taste debates — where two options are defensible, ask
  once (a decision Ask) and record the answer.
- It will not catch a claim that is simply untrue. It checks how you said
  it, not whether it's true. Substantiation stays human.
- It will not override a house rule because a draft reads better without it.
